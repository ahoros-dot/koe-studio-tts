# こえスタジオ

**Gemini 3.8 Flash TTS を日本語の画面で試せる、非公式の音声生成スタジオ**です。
Google AI Studio の音声生成画面を、日本語で使いやすくしたものを目指しました。

**https://ahoros-dot.github.io/koe-studio-tts/**

Google の公式アプリではありません。Google とは関係のない個人が作ったものです。

## できること

- **生成**: 台本をパートに分けて書き、パートごとに演技の指示（例: ささやき → 叫び）を付けられます。1人で読む／2人の掛け合いに対応し、`<laugh>` などのタグ35種類をボタンで差し込めます。作りながら再生する（ストリーミング）ので、長い台本でも1〜2秒で鳴り始めます。できた音声は WAV で保存でき、字幕（SRT / VTT）も書き出せます
- **読みのチェック**: 数字・英字・記号など、読み方が揺れやすい所に印を付け、かなに書き換える候補を出します（`18本` → じゅうはっぽん、`12.5度` → じゅうにてんごど など）
- **声を選ぶ**: 定番の30声と、日本語の声のライブラリ115声（東京・大阪・福岡のことば）。すべて試聴できます
- **聞き比べ**: 同じ台本を最大6声で作って並べます。声ごとの音量の差をそろえて比べられます
- **声をつくる**: 「どんな人の声か」を文章で書くと、新しい声を作れます（Voice Design）
- **履歴**: 作った音声はブラウザの中に残り、あとで聞き直したり書き出したりできます

API キーがなくても「キーなしで試す」で画面を一通り触れます（生成の代わりに試聴音声が返ります）。

## 使い方

1. [Google AI Studio の API キーのページ](https://aistudio.google.com/apikey) で、Gemini API のキーを作ります
2. こえスタジオの「設定」を開き、キーを貼り付けて保存します
3. 「生成」で台本を書くか、「例から始める…」から選んで「生成する」を押します

スマホでは、ブラウザのメニューから「ホーム画面に追加」すると、アプリのように開けます。

## API キーとデータの扱い

- キーは **あなたのブラウザの中にだけ** 保存します（「タブを閉じたら忘れる」も選べます）。このサイトの作者のところには届きません
- キーの送り先は Google の Gemini API（`generativelanguage.googleapis.com`）だけです。ページの設定（Content Security Policy）で、ほかの場所とは通信できないようにしています
- 台本と作った音声は「保存しない」設定（`store: false`）で Gemini API に送ります。Gemini API は何も指定しないとやりとりを55日間（無料版は1日）保存し、Google AI Studio のログに表示しますが、こえスタジオではそうなりません。残るのは、あなたのブラウザの履歴だけです
- 「声をつくる」で作った声は、名前と説明文と一緒に **あなたの Google のプロジェクトに保存** されます（最後に使ってから1年で消えます。アプリの「削除」でいつでも消せます）。同じキーを持つ人なら一覧で見られるので、説明文に個人的なことは書かないでください
- 料金は **キーの持ち主の Google アカウント** にかかります

## 料金と回数の上限

- Gemini 3.8 Flash TTS の料金は、音声1秒あたり25トークン、100万トークンあたり9ドル（2026年末までの価格）です。30秒で約1円です。画面に見積もりが出ます
- 有料の Tier 1 では、1分に10回、モデルごとに1日100回までリクエストできます（2026年10月に作者が確かめた値。変わることがあります）。1日の回数は太平洋時間の0時（日本時間の16時、冬は17時）に数え直されます
- 聞き比べは声の数だけ回数を使います。同じキーなら、AI Studio など別の場所で使った分も同じ枠から減ります

## 入れていない機能

録音から声をまねる機能（Voice Replication）は入れていません。本人の同意の録音が必要で、誰でも使える公開アプリでは悪用を防ぎきれないためです。

## 手元で動かす

ビルドは要りません。静的ファイルをそのまま配信すれば動きます（`file://` では動きません）。

```bash
npx --yes http-server . -p 8190 -c-1
node scripts/selftest.mjs   # 画面以外の部分のテスト
```

試聴音声は `scripts/make-voice-samples.mjs` で作っています（環境変数 `GEMINI_API_KEY` が必要です）。
