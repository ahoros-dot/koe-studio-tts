こえスタジオ Gemini 3.8 Flash TTS の非公式プレイグラウンド 非公式
キーなしで試すモードです。生成すると、台本ではなく選んだ声の試聴音声が返ります。

台本

台本は書いたとおりに読まれます。読み方の指示は「演技の指示」へ。<laugh> などのタグと、2人のときの |あいづち| だけは読まれません。

    読みのチェック

      話し手
      出力

      声の聞き比べ

      同じ台本を複数の声で作って並べます。声ごとに素の音量が違うので、そろえてから比べると公平です。リクエストは声の数だけ使います。

      比べる声（最大6つ）

      声をつくる

      どんな人の声かを文章で書くと、新しい声を作ってあなたの Google のプロジェクトに保存します（200声まで、最後に使ってから1年で消えます）。作った声は「生成」の1人モードで選べます。名前と説明文も一緒に保存され、同じキーを持つ人なら一覧で見られるので、個人的なことは書かないでください。

      その日の気分ではなく、どんな人かを書きます（年齢・声の質・高さ・なまり・話す速さ）。気分や演技は、生成のときの「演技の指示」で付けます。

      自分の声

        録音から声をまねる機能（Voice Replication）は入れていません。本人の同意の録音が必要で、誰でも使える公開アプリでは悪用を防ぎきれないためです。

        履歴

        生成した音声は、このブラウザの中にだけ保存されます。

          設定

          Gemini API キー

          キーは このブラウザの中にだけ 保存し、送り先は generativelanguage.googleapis.com だけです。書き出すファイルやコード表示には含めません。料金はキーの持ち主の Google アカウントにかかります。

          台本と作った音声は「保存しない」設定（store: false）で送るので、Google AI Studio のログ（Logs）にも残りません。残るのは、このブラウザの履歴だけです。

          キーは Google AI Studio の API キーのページ で作れます。

          保存のしかた

          リクエストの間隔

          音声を作るリクエストは1本ずつ順に送ります。有料の Tier 1 は1分10回までなので、既定は 6.5秒です。「回数の上限」と出るときは広げてください。

          Tier 1 には1日の上限もあります（モデルごとに1日100回。2026-10-04 に確かめた値）。太平洋時間の0時（日本時間の16時、冬は17時）に数え直されます。聞き比べは声の数だけ、試聴音声を作るのも1回ずつ数えられます。同じキーなら、AI Studio などほかの場所で使った分も同じ枠から減ります。

          読み辞書

          英字や固有名詞の読みを登録すると、「読みのチェック」で置き換えの候補に出ます。

            そのほか

            このアプリは非公式です。Google の音声生成ガイド・開発者ガイド（2026-10-04 確認）をもとに作っています。
